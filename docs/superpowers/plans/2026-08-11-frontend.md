# Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Angular app in `frontend/` that displays processing-service's daily
summary report and lets the user download it as CSV, correctly distinguishing "store
not ready yet" (`503`, keep polling) from "genuinely zero rows" (`200` with `[]`, show
empty state).

**Architecture:** A single standalone-component Angular app (no router, no NgModules).
An injectable `ReportService` owns all report state as signals (`status`, `entries`,
`errorMessage`) and a self-rescheduling polling loop for `503` responses. The one
feature component, `ReportComponent`, reads those signals directly in its template.
CSV download is a plain anchor tag relying on the browser's native download handling
plus processing-service's existing `Content-Disposition` header.

**Tech Stack:** Angular CLI 21.2.20 (standalone APIs, 2025 file-naming style: `report.ts`
not `report.component.ts`), TypeScript, `HttpClient`, RxJS `timer` for the retry delay,
Vitest as the unit test runner (Angular CLI 21's current default — see Global
Constraints), hand-written CSS (no UI component library).

## Global Constraints

- Angular CLI version: **21.2.20** exactly (`npx -p @angular/cli@21.2.20 ng ...` for
  every `ng` invocation in this plan) — this is the newest Angular CLI release that
  matches the Node version installed in this environment (`node --version` → confirm
  it satisfies `@angular/cli@21.2.20`'s `engines.node` range before running any step;
  at plan-writing time it was `v24.3.0`, which the 22.x line's `^24.15.0` requirement
  does *not* cover, but 21.x's `>=24.0.0` does).
- Test runner: **Vitest** (`ng new` default — do not pass `--test-runner=karma`). Use
  `vi.useFakeTimers()` / `await vi.advanceTimersByTimeAsync(ms)` for retry-timer tests,
  **not** Angular's `fakeAsync`/`tick` (confirmed during planning: `fakeAsync` needs
  `zone.js/testing`, which a fresh `ng new` workspace on this CLI version does not
  include).
- File naming: Angular CLI 21's default "2025" style guide — concise names
  (`report.ts`, `report.html`, `report.css`), not `report.component.ts`.
- Standalone components only, no NgModules, no router (single view, `--routing=false`).
- No UI component library (no Angular Material) — hand-written CSS only.
- `ReportEntry` field names are exactly `Client_Information`, `Product_Information`,
  `Total_Transaction_Amount` (mirrors processing-service's JSON wire format verbatim —
  no camelCase translation).
- processing-service runs on `localhost:8082`; the Angular dev server proxies `/api/*`
  to it via `proxy.conf.json` — the app code always calls relative paths
  (`/api/report`, `/api/report/csv`), never an absolute `localhost:8082` URL.
- Retry delay for `503` responses: exactly 3000ms, no retry cap.
- Design doc: `docs/superpowers/specs/2026-08-11-frontend-design.md` — consult it for
  the full rationale behind every decision above.

- [ ] **Step 4: Implement `ReportService`**

Write `frontend/src/app/report/report.service.ts`:

```ts
import { Injectable, signal } from '@angular/core';
import { HttpClient, HttpErrorResponse } from '@angular/common/http';
import { timer } from 'rxjs';
import { ReportEntry } from './report-entry';

const RETRY_DELAY_MS = 3000;

@Injectable({ providedIn: 'root' })
export class ReportService {
  private readonly _status = signal<'loading' | 'ready' | 'error'>('loading');
  private readonly _entries = signal<ReportEntry[]>([]);
  private readonly _errorMessage = signal<string | null>(null);

  readonly status = this._status.asReadonly();
  readonly entries = this._entries.asReadonly();
  readonly errorMessage = this._errorMessage.asReadonly();

  constructor(private readonly http: HttpClient) {}

  load(): void {
    this._status.set('loading');
    this._errorMessage.set(null);

    this.http.get<ReportEntry[]>('/api/report').subscribe({
      next: (entries) => {
        this._entries.set(entries);
        this._status.set('ready');
      },
      error: (err: HttpErrorResponse) => {
        if (err.status === 503) {
          timer(RETRY_DELAY_MS).subscribe(() => this.load());
          return;
        }
        this._status.set('error');
        this._errorMessage.set(
          err.error?.error ?? err.message ?? 'Unable to reach processing-service.',
        );
      },
    });
  }
}
```
